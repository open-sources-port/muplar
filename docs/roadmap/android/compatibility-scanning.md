# Compatibility Scanning Checklist

Stable area: repeatable APK triage, strict native import checks, scan logs, and
stub backlog reports.

## Done

- [x] `tools/run-apk-compat-scan.sh` runs APKs with `--strict-direct-imports`.
- [x] Per-APK logs are written under `build/apk-compat-scan/`.
- [x] Scan output classifies APKs as `launch-ok`, `java-runtime-required`, `native-deps-incomplete`, or `runtime-failed`.
- [x] Missing APK-local libraries and unresolved direct imports are summarized.
- [x] Markdown backlog reports are generated by default.
- [x] Java/ART backlog reports concrete sysroot inputs, including `app_process64`,
      bootclasspath jars, `libandroid_runtime.so`, and `libart.so`.
- [x] Clean dependency APK, Java-only APK, unsupported-import APK, and NDK AIDL APK are covered by the main test script.
